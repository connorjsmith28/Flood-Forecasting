Step-by-Step Detail

Step 1

Data Ingestion

Two loaders both return a pl.DataFrame sorted by (site_id, observation_hour).

pull_duckdb(...)   # parameterized SQL on DuckDB
pull_wandb(...)    # downloads W&B Parquet artifact

frequency="daily" → keeps only hour=12 observations
src/utils/helpers.py
Step 2

Feature Selection & Target Creation

Select only needed columns, then create the prediction target by shifting streamflow forward.

shift_amount = 1      # daily
shift_amount = 24     # hourly

target = streamflow_cfs_mean
         .shift(-shift_amount)
         .over("site_id")
src/preprocessing/preprocessing.py drops last shift_amount rows/site
Step 3

Lag Feature Engineering

Expands dynamic features into lagged copies. Static attributes (lat/lon) are not lagged.

for col in dynamic_cols:
  for lag in range(1, lag_window):   # e.g. 1..23
    col_lag = col.shift(lag).over("site_id")

n_features = n_dyn
           + n_static
           + n_dyn × (lag_window - 1)
src/preprocessing/preprocessing.py drops first lag_window rows/site
Step 4

Train / Val / Test Split

Chronological split preserving temporal order. Two modes available.

Mode A — single cut (split_time_days=None):
  train ← first 70 % of timestamps
  val   ← next 15 %
  test  ← final 15 %

Mode B — rolling chunks (split_time_days=365):
  Each N-day chunk independently split 70/15/15
  Prevents temporal leakage on long records
src/preprocessing/preprocessing.py
Step 5

Feature Scaling — TorchStandardScaler

Z-score normalisation. Fit on train only — no data leakage.

z = (x − μ) / σ

Global mode  (site_scaling=False):
  one mean/std per feature column

Per-site mode (site_scaling=True):
  separate mean/std per site

feature_scaler  ≠  target_scaler
src/preprocessing/preprocessing.py no leakage
Step 6

create_sequences — Sliding Window

Converts scaled DataFrames into 3-D tensors using a rolling window. Windows never cross site boundaries.

window_size = 72   # 72-hour lookback

for site in sites:
  for i in range(len(site) - window_size):
    X_seq = site_X[i : i + window_size]
            # shape [72, n_features]
    y_seq = site_y[i + window_size - 1]
            # label at LAST step of window
src/utils/helpers.py output: [N_seqs, 72, n_features]
